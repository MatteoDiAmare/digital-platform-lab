# Labb 00–09: så använder du dem

Labbarna görs först med stöd i undervisningen och kan sedan upprepas individuellt. Labb 00 är ett omtag för dig som vill bygga grunden från en tom mapp. Labb 01–09 använder samma lilla kursapp i detta repo. Gruppens valfria projekt och musikspelaren är separata tillämpningar av samma idéer.

**Arbetssätt i Labb 00:** gör ett synligt steg → upprepa själv → sätt namn på det du såg.

**Arbetssätt i Labb 01–09:** förutsäg → prova en sak → observera i sidan, DevTools och terminalen → förklara vad observationen visar → återställ avsiktliga fel. Ett svar från servern bevisar bara det som svaret faktiskt säger.

**Lektionsnummer och labbnummer är inte samma sak.** Exempelvis hänvisar lektion 4 till labb 03, lektion 5 till labb 04 och lektion 6 till labb 05. Labb 00–03 kan användas som repetition om teknikstrul eller begreppsflödet gjorde att du missade någon del.

Labb 00 öppnas direkt från `index.html` och behöver ingen server. För Labb 01–09 startar du i projektets rotmapp med `npm.cmd start` i Windows PowerShell eller `npm start` på macOS/Linux/Codespaces. Öppna `http://localhost:3000` lokalt, eller den vidarebefordrade porten i Codespaces. Ingen installation av externa npm-paket krävs.
