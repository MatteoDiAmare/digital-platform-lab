# Public application files

This directory contains the files loaded by the browser:

- `index.html` for page structure
- `styles.css` for presentation
- `app.js` for client-side behaviour

The files are kept separate so students can see which part controls structure, presentation, and behaviour. The pilot sends a synthetic booking event to the server and displays the response. Later exercises will add browser storage, identifiers, tracking rules, and consent choices.
